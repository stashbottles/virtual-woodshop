# Virtual WoodShop

A browser-based woodworking simulator focused on end-grain cutting boards and glue-ups.

Built as a personal project to model real shop processes in code — material tracking, cutting/joinery transformations, pattern generation, inventory/scrap handling, and workflow planning.

## Tech Stack

- React
- TypeScript
- Vite

## Features

- Material and inventory tracking
- Visual pattern generation for end-grain designs
- Cutting and joinery operations (rip, crosscut, flip, rotate, glue)
- Scrap and leftover handling
- Workflow previews
- Undo / redo

## Getting Started

```bash
npm install
npm run dev
